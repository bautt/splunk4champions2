Dashboard Studio is the dashboard you edit on a canvas. A dashboard is searches, the pictures those searches draw, and the controls that change them.

<img src="/static/app/splunk4champions2/images/iot_factory.gif" alt="Example Dashboard Studio dashboard"/>

| Piece | What it is |
|---|---|
| Data source | An inline search, a saved search, or a chain that reuses another search |
| Visualization | A chart, table, or markdown block. It has an id, a type, and one data source |
| Input | A control that writes a token. Searches and titles read that token |
| Layout | A grid. Each panel has a position and a size |

The next page runs one search and feeds several panels from it.
