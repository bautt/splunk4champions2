### Install

All visualizations are pre-built. Clone, run `build.sh`, install the resulting `.tar.gz` via **Apps → Manage Apps → Install app from file**.

```bash
git clone https://github.com/rcastley/splunk-custom-visualizations
cd splunk-custom-visualizations
./build.sh gauge          # any standalone viz
./splunk_health/build.sh  # full health dashboard bundle
```

**Requires:** Splunk Enterprise 10.2+ or Splunk Cloud · Node.js 18+ for building (not needed at runtime)

### Building Your Own with Cursor

The repo includes a `/splunk-viz` skill. Describe what you want and it scaffolds the app:

```text
Using /splunk-viz, create a visualization that shows a donut chart
with a center label. It should accept "label" and "value" columns.
```

Then build and install:

```bash
./build.sh my_viz_name
$SPLUNK_HOME/bin/splunk install app dist/my_viz_name-1.0.0.tar.gz
```
