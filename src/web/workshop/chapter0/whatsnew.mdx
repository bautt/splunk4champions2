# What's new in the app

The repository includes a root-level `WHATS_NEW.md` summary and the <Link to="https://github.com/bautt/splunk4champions2/releases" openInNewContext>Releases</Link> page remains the source for full tag descriptions on <Link to="https://github.com/bautt/splunk4champions2" openInNewContext>GitHub</Link>. Below: recent **app** versions in this build, then **highlights** from an earlier GitHub release so you can see the same story as the repo.

If you build from source, the **exact** app version is shown on the **Setup** health check page and under **Settings → Apps → Splunk4Champions2**.

## This build (2.11.77)

- **Workshop-wide colour schemes:** the Setup colour picker now restyles the whole workshop (top chapter bar, subchapter bar, table headers, lab callouts, complete-lab cards, primary search button, Setup toggles) instead of just the lab blocks. Four schemes: **Blue / Navy** (default), **Brown / Dark Red**, **Blue / Yellow** (Ukrainian flag intensity), and **Pink / Orange** (Splunk.com brand intensity).
- **Live preview in the picker:** switching schemes immediately previews a `LabBlock` callout and a complete-lab card so trainers see the effect before committing.
- **Picker tucked away:** the colour scheme panel is collapsed by default behind a subtle *"change colour scheme"* link below the Setup health check, keeping Setup focused on readiness checks.
- **Lab icons clarified:** atomic hands-on `LabBlock` callouts keep the hammer icon; the five complete-lab summary cards now use a flask icon to visually separate "single exercise" from "end-to-end lab".
- **Scheme-aware primary buttons:** the workshop search button and the Setup toggle buttons (Standard / Large Room and the four scheme buttons) now match the active scheme instead of staying Splunk green, including hover and focus states.
- **Theme-aware navigation:** chapter bar and section bar default to a pale blue tint that matches the Blue / Navy baseline; each scheme overrides them so the workshop visually agrees with itself end-to-end.
- **Persistence unchanged:** the chosen scheme and the trainer display mode are still stored in browser local storage and broadcast via custom events so SPA navigation keeps the chosen theme.
