The built-in bar chart below is the picture. Your own visualization is the exercise. Splunk runs the search. Your code only draws the table it returns.

<WorkshopViz
    title="Web 120, Database 80, Mail 40"
    viz="bar"
    spl={`| makeresults count=3
| streamstats count AS row
| eval label=case(row=1,"Web",row=2,"Database",true(),"Mail")
| eval value=case(row=1,120,row=2,80,true(),40)
| table label value`}

| JavaScript | The instructions: read the rows and draw bars. |

| JSON | The menu name and the editor form. Not SPL. |
| Build | Produces browser files. It does not prove the chart works. |
| Package | Wraps those files as an app you can install. |

The contract is two columns. `label` is text. `value` is a number that is zero or greater. Column order does not matter. The names do.

<LabBlock title="Checkpoint">
